# 分档标准

## 1. 通用五档

先按本单元的目标和实际影响选档，再核对其专用锚点。不能按正确条数、篇幅、工具次数或诊断项通过比例机械换分。下面的例子均为虚构校准材料。

| 分数 | 含义 | 边界 |
| --- | --- | --- |
| 4 | 全部必要要求满足 | 现有证据充分覆盖该单元全部已触发的必要要求，核心结果、依据、方法及适用的局部要求均满足，没有已确认缺陷。只验收本题义务，不以额外引用、后状态查询、固定解法、篇幅或裁判偏好的扩展内容作为满分条件。 |
| 3 | 核心成立且有非关键局部缺陷 | 该单元的核心结果、依据和方法在当前有效范围内成立，全部重要子交付可用，但存在真实非关键局部缺陷；其剩余修复不需替换核心依据、重建方法、重做关键产出或改变核心结论。原过程单元曾发生且已完整恢复的候选局部错误，也按评判规则中的恢复要求保留在3分；不能把仍未恢复的重要失效降格称为局部瑕疵，也不能无真实缺陷而给3分。 |
| 2 | 部分重要子交付独立可用 | 该单元原本可分离的重要子交付中，至少一部分已独立、完整、有效地满足要求并可使用，但其他重要部分未满足。须指出可分离子交付、其完整验收依据和未满足部分；不按答对数量、比例、篇幅或细项通过数机械判2分。受共同错误依据、方法或映射污染而偶然正确的结果不算独立有效子交付。 |
| 1 | 仅有实质支持材料或步骤 | 该单元已有能服务本题的实质有效材料、识别或步骤，但没有任何原本可分离的重要子交付独立完整可用；关键产出失效，必须重做核心部分。准备工作、局部正确步骤与可直接使用的子交付须分开判断。 |
| 0 | 无实质有效完成 | 现有证据已足以确认：该单元没有实质有效完成。只有抄题面、泛泛计划、自称完成、无效尝试或与本单元目标无关的内容，不构成1分。0不代表未核实、不适用或记录未采集。 |

相邻档位的关键区别：

- 4与3以是否存在真实、已确认且属于本单元的非关键局部缺陷区分。 全部必要要求均有充分证据支持且本单元无已确认缺陷为4；当前核心和所有重要子交付成立，仅有非关键局部缺陷，或本单元存在按恢复规则保留的已完整恢复局部过程错误为3。裁判希望增加的可选内容、无证据的疑点或未触发要求不构成3分依据。
- 3与2以当前重要部分是否全部成立，以及剩余修复是否涉及核心依据、方法或关键产出区分。 全部重要交付现已有效，且仅有非关键局部缺陷或已完整恢复的局部过程错误，可为3；另有重要部分仍未满足，但已完成的可分离重要子交付独立完整可用为2。不能把整体仍失效的结论拆成若干局部优点来凑2分；也不能仅因历史上重做过核心工作而忽略已经完成的恢复。
- 2与1以是否存在原本可分离、独立完整有效的重要子交付区分，不以正确数量或比例区分。 能指明一个已按本单元要求完整验收、无需重做便可独立使用的重要子交付为2；只有服务本题的材料、步骤或尚不完整的产出，关键交付仍须重做为1。计算草稿不自动成为T2交付；被共同错误依据污染的偶然正确结果不支持2分。
- 1与0以是否已有服务本题的实质有效支持材料或步骤区分。 已取得适用材料、完成有效抽取、形成可核对的正确中间步骤等，且确实支持本单元目标，可为1；仅抄题面、泛泛计划、自称完成、无效调用或无关内容为0。证据不足或适用性未知继续记未核实；确认不触发则不适用，均不补0。

## 2. 状态、分数与区间

核心单元的五档含义和专用锚点保持0–4分。每项给出状态、档位、`score`、`score_range`和简短理由；最终解答总分另用第4节的0–10分标准。

| 状态 | 核心单元 | 最终解答总分 |
| --- | --- | --- |
| `met` | `score: 4`，区间为空。 | `score: 10`，区间为空。 |
| `violated` | 0–3整数单点；程度待核可用0–3内区间。 | 0–9整数单点；程度待核可用0–9内区间。 |
| `unverified` | 单点为空，0–4内有宽度的区间。 | 单点为空，0–10内有宽度的区间。 |
| `not_applicable` | 单点与区间都为空，不补0或满分。 | 不允许：完整答案的最终交付始终需要评价。 |

适用项目在单点与区间之间只选一种。单点档位由整数分数确定；区间的档位写“待核”，保留已确认缺陷的状态与上界，不取中点。区间表示评分证据或程度的不确定性，不是事件概率或统计置信区间。

判断某项不适用时，须确认题目和实际行为都没有触发；题目要求但候选漏做的项目仍适用。没有记录、没有核实和不适用分别表达。12个单元、24项诊断均保留，不删除未触发项，不按适用项数量改变总分标准。

当前Skill只交付单题JSON，不生成六轴数字聚合、均分、权重或模型排名。结构与引用检查由执行器按需处理，不能替裁判选择档位或改变语义判断。

## 3. 各核心单元锚点

通用档位与恢复规则适用于下列全部单元；其他单元的错误不自动影响本单元评分。

### T1 对象、目标与公开约束

目标：识别并实际落实题目指定的对象、任务目标、范围、期间、指标、单位及公开约束。

| 分数 | 判定锚点 | 校准例 |
| --- | --- | --- |
| 4 | 对象、任务目标、范围、期间、指标、单位和其他已触发公开约束均被正确识别并落实，现有材料足以验收全部必要要求。 | 要求按万元比较甲乙公司2025年一季度收入；回答及实际查询均采用甲乙、该季度与收入指标，并正确按万元呈现。 |
| 3 | 核心对象、目标及决定结果的约束均已落实，所有重要子任务对齐；仅有真实的非关键公开约束偏差，局部调整即可满足，不改变核心工作。 | 甲乙公司的指定期间和指标都正确完成；题目还要求补充说明只限一段，回答把同一段非关键背景拆成两段，合并即可。 |
| 2 | 至少一个原本可分离的重要子任务已完整落实其对象、目标和全部必要约束，另一个重要子任务仍有对象、目标或关键范围错误；有效部分不依赖错误部分。 | 分别要求甲公司2025年收入与乙公司2024年利润。甲项对象、期间和指标均正确落实且可独立使用，乙项却执行为2025年收入。 |
| 1 | 已完成能支持本题的实质约束识别或落实步骤，但核心对象、目标或关键范围仍错位；没有一个原本可分离的重要子任务在本单元完整对齐。 | 已把甲公司年收入对应到正确的年报指标和单位，但实际查询与结论全用了乙公司的数据；这些映射可复用，甲公司的目标任务须重做。 |
| 0 | 已确认实际工作与题目对象、目标及必要约束均无实质有效对齐；或只有复述要求和泛泛承诺，没有有效识别或落实。 | 要求比较甲乙公司的2025年收入，回答只重复题目后给出丙公司的股价走势，未完成任何相关约束落实。 |

### T2 必要覆盖与实际交付

目标：按题意实际交付全部必要对象、字段、子任务与成品，并以实质覆盖判断完成度。

| 分数 | 判定锚点 | 校准例 |
| --- | --- | --- |
| 4 | 全部必要对象、字段、子任务与成品均已实际有效交付，允许的终态与题意一致，且实质覆盖证据充分。 | 题目要求处理甲乙丙记录；回答准确交付每条结果和必要说明。没有属于‘规则未覆盖’的记录，题目未要求逐类列示，因此未另写该空类不影响4分。 |
| 3 | 核心结果和全部重要子交付均已实际完整交付，仅遗漏或未满足真实的非关键局部交付要求；局部补齐不改变核心结果、依据或方法。 | 两份必要分析表及解释均已有效交付，只漏了题目另要求的一条非关键术语释义，补一句即可。 |
| 2 | 至少一个原本可分离的重要子交付已实际交付，满足其必要要求且可独立使用；其他重要对象、字段、子任务或成品尚未有效交付。 | 要求分别交付甲项目预算表和乙项目排期表。甲表字段齐全、结果有效并已交付，乙表只有占位标题；甲表不依赖乙表。 |
| 1 | 已实际交付相关的实质结果片段或部分必要字段，但没有任何原本可分离的重要子交付完整有效；关键交付仍须补做或重做。未交付的内部材料、草稿或制作步骤不在T2获得该分。 | 要求交付含结果及必要解释的预算表，回答实际给出几个可核验的预算字段，但缺核心结果和解释，不能独立构成任何完整子交付。 |
| 0 | 完整捕获已确认没有任何实质有效交付；只有计划、自称完成、占位或未交付的内部准备。其他单元可确认的有效计算或取证不替代本单元所需交付。 | 要求交付可用预算表，候选虽在可见分析中算出输入，却只向用户交付‘稍后制作’及空表，没有实际结果；分析中的正确计算另评L1。 |

### E1 依据可追溯、范围与时点

目标：使实际依赖的依据可定位，并适用于所支撑对象、事实范围、观察窗口与版本。

| 分数 | 判定锚点 | 校准例 |
| --- | --- | --- |
| 4 | 全部重要依据均可定位，材料所支持的对象、范围、时点和版本与用途匹配，摘要、全文及历史汇编范围按实际需要区分清楚。 | 回答使用已提供的2024年政策档案，准确标明文件、章节及适用期间，并将摘要能支持的范围限于摘要内容，全部依据要求可核验。 |
| 3 | 核心依据及全部重要判断的对象、范围、时点和版本均适用且可定位，仅有不影响支撑关系的真实局部追溯缺陷，补正即可。 | 核心政策均对应正确历史文件与页码，只有一条非关键背景来源的章节号写错；同一已提供文件中的原文仍可直接定位，改章节号即可。 |
| 2 | 至少一个原本可分离的重要判断已有完整、适用且可定位的依据，另一个重要判断使用不适用或不可追溯的依据；有效依据链可独立成立。 | 分别核验甲乙两机构的2024年政策；甲项有正确历史版本与定位片段，乙项却使用2026年修订版，甲项的依据链仍独立可用。 |
| 1 | 已取得可服务本题的实质来源或定位线索，但关键范围、时点或版本尚未正确用于任何完整可分离的重要判断；核心依据须重建。 | 已找到甲机构年度档案及可定位目录，但唯一核心判断采用了明确不适用的下一年度修订版；目录可支持重查，当前历史判断的依据须重建。 |
| 0 | 已确认没有任何适用且可定位的有效依据，也没有形成可服务本题的实质取证材料；仅有无关来源、失效指向或泛泛声称‘据资料’。 | 要求依据给定历史档案判断甲机构政策，回答全部依据是另一机构的无关宣传页，没有适用片段或其他有效取证材料。 |

### E2 抽取与主张忠实于材料

目标：正确抽取对象、字段、数值、单位和倍率，使重要事实与所用材料的语义支持对应。

| 分数 | 判定锚点 | 校准例 |
| --- | --- | --- |
| 4 | 全部已触发的重要抽取和事实主张忠实于材料，对象、行列、指标、单位、倍率及支持范围均正确，证据与主张语义一一相符。 | 材料表头为万元、行中分别列收入和利润；回答正确取收入行并换算单位，且只断言材料明确支持的事实。 |
| 3 | 全部核心事实和重要主张均被材料支持，抽取对象与量纲正确；仅有非关键局部字段或背景转述缺陷，修复不改变核心事实和结论。 | 甲乙的收入和同比均正确抽取并受原文支持，只有一条非关键背景说明把‘约十家’转述为‘十家’，改回约数即可。 |
| 2 | 至少一个原本可分离的重要字段组或主张已完整忠实于材料，其他重要部分存在抽取或语义支持错误；有效部分不受共同错读污染。 | 甲乙为两个独立核验对象；甲的收入、单位及说明均忠实于其表格，乙却把利润列当收入列，甲项不依赖乙项。 |
| 1 | 已有有效识别字段或抽取的实质支持步骤，但没有任何可分离的重要主张被完整、忠实地支持；关键主张需重新抽取或重建。 | 已正确识别表中‘收入’行与万元倍率，但唯一需交付的同比判断混用相邻年份，尚未形成任何完整可用的收入主张。 |
| 0 | 已确认没有忠实于材料的实质有效抽取或主张支持；关键内容均被错读、捏造或与材料无关，且无可复用的有效抽取步骤。 | 材料只给甲公司的收入，回答凭空列出甲的利润和乙的债务，并称均出自该表，没有任何正确抽取。 |

### L1 分类、比较、集合与计算

目标：正确运用概念、类别、比较基准、集合规则、排序、公式及算术，得到与要求相符的逻辑结果。

| 分数 | 判定锚点 | 校准例 |
| --- | --- | --- |
| 4 | 全部已触发的概念、分类、比较、筛选、集合、去重、排序、公式、输入引用和运算正确，必要范围与舍入要求均满足。 | 回答正确区分首次覆盖与上调，以同一主体的前后记录比较，按AND筛选、去重后计算合计，并满足指定舍入。 |
| 3 | 核心分类、比较、集合、公式和运算均成立，所有重要结果可用；仅有非关键的局部逻辑或数值呈现缺陷，局部更正不改变核心排序、集合或结论。 | 必要筛选、合计和排序全对，只有非关键附表一项按题目要求保留两位小数时多留了一位；按要求舍入不改变任何决策。 |
| 2 | 至少一个原本可分离的重要分类、集合或计算子结果已完整正确，其他重要子结果失败；正确部分不依赖错误的共同规则或输入映射。 | 独立要求计算甲方案净现值和乙方案回收期；甲的公式、输入引用与运算均完整正确，乙错用回收期公式，甲结果可单独使用。 |
| 1 | 已有服务本题的正确概念识别、公式或中间运算，但关键逻辑产出失效，尚无原本可分离的重要子结果独立完整可用。 | 唯一任务是按‘同时满足甲乙条件’筛选后求和；候选正确逐项比较阈值，却用OR代替AND组成最终集合，筛选合计须重做。 |
| 0 | 已确认没有任何实质有效的分类、关系判断或计算步骤；只有无关公式、随意答案或全程无效运算。 | 要求按净额排序并计算合计，回答直接按名称字母排序且随意报出一个总数，没有有效分类、集合或计算步骤。 |

### L2 推断与方法自洽

目标：使解释、推断、预测及其假设、方法与结论自洽，遵守实际可支持的推断关系。

| 分数 | 判定锚点 | 校准例 |
| --- | --- | --- |
| 4 | 全部重要推断由其实际使用的有效方法与假设支持，解释和结论自洽，相关、因果、条件结果及预测边界均处理正确。 | 回答用与裁判不同但有效的情景模型，在明确假设下推出甲情景预测，区分观察相关与因果，并保持方法和结论一致。 |
| 3 | 核心方法、假设及全部重要推断自洽成立，只有非关键辅助解释存在真实局部推导缺口，补足不需更换核心方法、假设或结论。 | 主模型及两项核心预测均由给定假设推出；题目另要求的一段非关键辅助推导漏写一个已满足的前提，补明该前提即可，主推断不变。 |
| 2 | 至少一个原本可分离的重要推断已由适用方法和假设完整支持，另一个重要推断的方法或推导失效；有效推断可独立成立。 | 独立分析甲乙两种机制；甲项在明示假设下由有效模型推出条件结论，乙项却用相关性证明因果，甲项不依赖乙项。 |
| 1 | 已有相关且有效的假设识别或分析步骤，但核心推断依赖无效关系或方法，尚无可分离的重要结论独立成立，须重建核心推断。 | 已正确整理一项观察研究的变量及组间差异，却在唯一核心结论中直接把相关关系当成因果效应，没有独立有效的子结论交付。 |
| 0 | 已确认没有能支持本题的实质有效方法或推断步骤；只有结论断言、无关方法名或不产生有效推断的尝试。 | 要求解释甲现象，回答只写‘采用科学方法可知必然如此’，没有相关假设、推断关系或有效分析。 |

### A1 行动路径与可见参数

目标：选择服务任务目标的取证或行动路径，并在实际调用中落实对象、过滤条件、期间、单位、权限与公开限制。

## 4. 最终解答质量总分：0–10分

总分概括题目要求的最终解答是否正确、完整、有必要支撑且可使用。先按五档判断实际交付，再按档内的缺陷影响程度选整数分；不把12个分项相加、平均，不按正确条数、诊断通过率、工具次数或篇幅机械换算。题目没有要求的推导、引用样式或扩展内容不成为满分门槛。

| 档位 | 总分 | 判定边界 |
| --- | --- | --- |
| 全部满足 | 10 | 全部必要要求满足，关键结果及必要依据成立，重要交付可用，没有已确认的交付质量缺陷。 |
| 非关键局部缺陷 | 9 | 核心和全部重要交付成立；缺陷影响很轻微，不妨碍重要结果的理解或使用。 |
| 非关键局部缺陷 | 8 | 核心和全部重要交付成立；缺陷影响一部分非关键内容的理解或使用，影响范围有限。 |
| 非关键局部缺陷 | 7 | 核心和全部重要交付仍成立；非关键问题影响范围较广或较明显，但没有重要交付失效。 |
| 部分重要结果有效 | 6 | 已有完整、独立有效的重要成果覆盖核心需求的重要部分；仍有其他重要交付未满足，因此不能进入7分档。 |
| 部分重要结果有效 | 5 | 可独立使用的重要成果与另一些未满足的重要需求并存；有效部分完整成立，剩余失效对任务有实质影响。 |
| 部分重要结果有效 | 4 | 仅有范围较有限但独立完整的重要成果可用；其余主要交付仍失效。不能把零散正确片段凑成该档。 |
| 只有有效片段或步骤 | 3 | 已交付可复用的关键结果片段或有效方法，但没有原本可分离的重要子交付完整有效。 |
| 只有有效片段或步骤 | 2 | 已交付直接服务任务的有效材料或步骤，关键结果尚未形成，核心产出仍不可使用。 |
| 只有有效片段或步骤 | 1 | 仅交付少量实质有效片段，核心目标与主要交付均未实现；与完全空泛的计划或无关内容区分。 |
| 无实质有效交付 | 0 | 完整捕获确认没有任何实质有效交付；只有计划、自称完成、占位、无关内容或全失效的结果。内部准备不能代替最终交付。 |

档内分数的理由必须落在本题的实际影响：哪些重要成果独立有效、哪些要求未满足、缺陷影响什么使用范围。不能只写“总体不错”或因为多一个错误就固定少一分。难以区分相邻分数且缺口影响评分时，保留区间并说明具体原因。

关键依据或方法错误，导致全部重要结果缺乏有效支持时，即使终值碰巧正确，也不能评10分或把受共同错误污染的结果当作独立有效成果。已有独立有效交付的部分照常验收，不因另一处错误全盘否定。

最终解答与过程分项分别评价：过程曾有局部错误但已完整恢复，最终交付的正确结果和适用依据可以独立支持高分；原过程单元按恢复规则保留相应诊断。其他附加内容的真实缺陷按实际影响评价，不能因核心文件已交付而豁免，也不自动把独立有效的文件判为未交付。

预测题按候选当时可得的信息、假设和推断评价回答质量。事件未来命中或落空另行记录，不要求当前裁判预知结果，也不以裁判自定概率区间作为总分依据。
