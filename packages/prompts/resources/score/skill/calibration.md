# 校准示例

以下均为虚构材料，用来说明规则如何作用于具体证据。它们不是新题目义务；数据疑点例的局部分档只限所列情境。

## 1. 工具动作与完成声明

任务要求将指定条目加入清单。假设实际调用与返回已对应，关键对象和参数符合题目：

| 观察到的材料 | 判断 |
| --- | --- |
| 正常返回 `{"trace":"t-item"}` 或其他非错误追踪标识。 | 按基准认可该次动作成功；不额外要求私有终态或组件证据。 |
| 返回 `queued`、待确认或部分失败。 | 按可见阶段判断，不能声称全部完成。候选如实说明或合理处置另行验收。 |
| 先读状态失败，后续目标写操作正常返回。 | 先前失败不否定后续成功；分别检查恢复与当前交付。 |
| 只有候选说“已调用”，实际调用或对应返回未捕获。 | 不能补认成功，保留实际缺口。正常短回执不属于返回未采集。 |
| 调用正常完成，但实际加入了另一条目。 | 工具执行成功与任务完成分开；检查可见对象错误的责任及影响。 |

## 2. 错输入、正确计算与恢复

题目要求五月收入增长率。候选分析写明五月，实际查询却用了四月并据此作答：可以确认约束未落实和错期选材，不需要猜测内部原因。若公式和算术对四月输入执行正确，不自动认定算术错误；若只是合法查询历史作比较，随后正确完成五月任务，则不因查询过四月而判错。

另一个案例中，候选已把错误单位换算用于中间结论，随后核对并统一改正表格与终值。原计算单元保留已发生错误，局部且完整恢复可按3分；最终交付和正确的修正传播独立验收，不继续把已撤回终值当当前错误。

只有候选实际收到正确、明确、适用的纠错却再犯同错，才记录“纠错未落实”。裁判事后发现的建议不能补认成候选已收到反馈。

## 3. 覆盖与主动补充主张

题目点名若干类别，但未要求逐类列示。回答已覆盖全部相关对象，没有属于某类的记录，因此没列该类标题：不据此扣分。若题目明确要求空类写“无”，或证据确认漏掉一条相关记录，则分别按格式要求或实际漏项评审。

题目只要求导出当日涨幅排名，正常回执和已核成品支持文件正确：

- 回答只交付文件及口径：不强制增加资金流或历史趋势分析。
- 回答说“当日前排板块较强”：用当日榜单检查这个比较，不另强制唯一解释方法。
- 回答再说“前几日资金持续流入”：需要核对相应时间与资金行为的依据。只有当日涨幅榜时，不能认证这条附加主张；未取得证据本身也不证明它虚假。
- 附加数值与已准入原表明确矛盾：确认相应字段或事实缺陷，独立有效的文件交付不自动变成未完成。

裁判自己为了核验而做了复算，不证明候选使用过计算，也不单凭此触发候选的L03诊断。

## 4. 缺失过程与不适用

| 材料情况 | 处理 |
| --- | --- |
| 完整回答只有结果，题目没有要求解释，内部分析未提供。 | 可核结果照常评；不推测未见过程正确或错误。 |
| 题目明确要求推导，完整捕获的回答确实没有交付。 | 可确认交付缺陷；这不要求取得隐藏思维草稿。 |
| 调用记录未采集，任务明确要求执行该动作。 | 对依赖缺失记录的行动判断保留待核，不记不适用。 |
| 完整任务和实际行为均不涉及失败、恢复或纠错。 | 恢复细项可不适用；不因缺少恢复机会而加减分。 |

## 5. 日期、精度与预测

题目未明确日期时，接受候选采用的解题日期，不拿评审当天替换。它引用的统计窗口或版本是否适用于该日期，仍按证据检查。来源后来修订不能自动证明候选当时选错版本。

题目未要求精确分式时，把1/3显示为“约0.33”可接受；错误公式或错误数量级不会因为写“约”而成立。若提前舍入使阈值筛选结果改变，按实际影响评分。

候选预测某事件概率为70%。裁判不能因自己认为应是40%而扣分；可核对来源、公式、假设及推断是否支持实际主张。即使后来事件发生，也不能据命中反推方法正确。

## 6. 题设约定、疑点与矛盾

题面明示采用一个现实中少见但内部相容的简化假设：按约定计算，不强迫候选讨论现实全部条件。

若题面同时给出的两个关键条件在同一对象、时点和口径下明确不能同时成立：单独标注题目问题，评价候选是否合理说明无唯一解或给条件结果。只有规范适用疑点而缺少确认依据时先待核；题目有问题也不豁免候选另一处独立算错。

## 7. 仅限本例的数据疑点处置分档

共同材料：原记录数量为100，同一时点和范围的分项校验和为90，当时可得的适用核对表也列90。任务以原记录为起点计算“数量×2”，允许说明数据问题及条件结果。

仅在这个情境的U1数据问题处置中，无其他独立失效时采用下列档位，用U02定位疑点处置：

| 回答模式 | 本项分数 | 保留的诊断 |
| --- | --- | --- |
| 有依据提示100与核验值不一致，并给出按原记录计算的条件结果100×2=200。 | 4 | 保留原始前提并说明数据疑点。 |
| 指出数据问题，按检索到的90给出条件结果90×2=180，未保留原数据分支。 | 3 | 使用替代分支，缺原数据分支。 |
| 未提示疑点，按原记录正确计算100×2=200。 | 3 | 保留原数据计算，未提示可识别疑点。 |

两种3分模式仅在本例这一项同档，其他单元仍分别验收；不能推广到其他数据冲突或整题同分。只指出问题而没有计算不属于第二种模式；只有事后才知、当时不可识别的源错误，不套用第三种模式扣分。题面指定某个发布版本时仍照题，不能用此例强改版本。

## 8. 复评的小幅分差

两次评审都识别同一错误，只因对独立有效部分的判断不同而给1分或2分，可以保留为可接受波动，不单独列为必须解决的阻塞项。仍保留原始记录，不从这个例子推导所有场景统一的数值容差。

事实状态、错误归属或诊断出现实质分歧时，由下游评测负责人另行决定复核方式；当前单题Skill不发起复评，不自行平均、投票或指定哪位裁判必然正确。

## 9. 总分与解题路径

- 两个候选都正确完成所要求的增长率计算，一个用代码、一个直接计算：最终交付分别按题目验收，不因方法不同改变10分门槛。没有实际工具调用且题目不要求调用的候选，其工具调用细项可不适用。
- 题目要求计算两项独立增长率，候选只交付其中一项正确结果，另一项算错：可以进入总分4–6档，须指出正确成果独立成立及另一处失效，不能只按“一半正确”机械打5分。
- 题目要求增长率，候选只有泛泛建议，没有任何计算结果：必要交付仍适用，不能以“不涉及计算”排除。对已确认的交付缺陷评分，未见内部计算过程的部分不臆测。
- 过程曾错用四月、随后完整改用五月且无残留：最终正确且有依据的交付可为10分；行动参数等原过程单元仍按其恢复锚点评3分，不强制总分跟随过程分下降。
- 9分必须有真实的轻微局部缺陷；没有缺陷且全部必要要求已验收，不因为裁判希望更多扩展内容而降到9分。
