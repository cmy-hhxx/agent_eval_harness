# 评判规则

## 1. 评审范围

本基准评审正常、完备且可解的题目。题面未直接给出的信息允许通过检索、材料或常识取得；缺少不可自行补足的关键条件、必须反问才能继续的题目不纳入本基准。候选自称缺信息不自动证明题目不完整。裁判没有取得全部证据，按受影响项目保留待核。

必要交付和约束由公开题目确定。接受满足任务的合理替代方法，不增加裁判偏好的篇幅、标题、工具、引用样式或唯一解法。未要求逐类列示时，空类别没有标题或“无”字不算遗漏；真正的完整度问题须指出缺少的对象、字段、子任务或必要说明。

候选主动增加的重要事实和推断也在评审范围内。核对它实际声称的对象、时间、范围和强度；文件正确交付不自动证明附加分析成立。题目未要求、候选也未提供的扩展分析不产生新义务。附加内容的问题按实际影响评分，不自动否定独立有效的核心交付。

## 2. 证据与判断

分别判断事实真值、证据支持和表述强度。引用可定位不等于支持主张，仍须核对其内容；工具返回和候选自述也不是所有世界事实的独立金标。公开材料指可独立核对并准入的材料，不限于互联网上发布的内容。

已提供且来源明确的分析、调用和返回可以使用。没有提供内部过程时，不推测其正确或错误；能由回答或其他证据确认的部分继续评审，确实依赖缺失记录的部分保留待核。完整回答缺少题目明确要求交付的依据或步骤，仍可判交付缺陷。往轮问答仅提供已知背景，不据此追加当前题目义务。

| 状态 | 判断条件 |
| --- | --- |
| `met` | 本项适用，证据充分支持全部已触发关键要求满足。 |
| `violated` | 本项适用，有可定位的具体缺陷。 |
| `unverified` | 适用性、必要证据或程度尚不能确定，写明具体缺口。 |
| `not_applicable` | 有依据确认本项没有触发。 |

缺证本身不等于错误，也不等于不适用。已确认错误和其他未知可以同时存在；不能因另一部分未知而抹去已确认缺陷。核验要覆盖本单元全部已触发关键要求，不能用一个满足的细项证明父单元整体满足。

## 3. 时间、数值与预测

**时间。** 题目明确日期或范围时照题核验；未明确时默认候选采用的日期正确，包括未附绝对日期的“今天”“最近”。不拿请求、生成、采集或评审时间另定标准。该默认仅确定接受的日期锚点；来源发表时间、统计窗口、日期字段及相对该日期的适用性仍须检查。

**数值。** 有明确精度或容差要求时照题核验；否则接受符合题意和单位的正确舍入，不默认要求分式或更多小数位。提前舍入改变阈值、排序或核心结论，按实际影响评价；“约”不豁免错误公式、单位、算术或字段读取。没有依据时不发明统一百分比容差。

**预测。** 检查候选依据、时点、假设、方法与推断衔接，不生成或参考裁判自定的合理概率区间。题面或明确方法给出的数学约束照常验收；未要求时不强制概率表达或唯一可复算映射。预测命中或落空不能单独证明过程好坏，单条轨迹也不能证明随机猜测或概率校准。事后结果及长期概率指标另行评估，不把后见信息追加为候选当时义务。

## 4. 工具动作与交付

实际调用与返回可对应，关键动作、对象、参数符合任务，且没有明确错误、失败、待处理、待确认或部分失败等相反信号时，默认该动作成功。编号、追踪标识、可视组件标识等正常回执同样适用；不因私有后状态、组件或API契约无法取得而再判未知，或认定完成声明失实。

按这项约定认可动作，不等于裁判已查看后台。只有计划、自述或打印出的JSON不能证明调用发生；调用或返回确未捕获时保留采集缺口。正常短回执与返回未采集须区分，全局记录不完整也不否定已完整取得的局部调用。

明确排队、失败或部分完成按实际范围判断。正常工具执行了错误对象或参数，仍不等于完成用户任务；但不能从不明私有参数含义推定错误。工具服务失败不自动归责候选，合理恢复或如实停止分别验收。先前失败不自动否定后续成功。

动作成功、成品质量和任务全部完成分别检查。题目另有明确核验要求时照题验收；文件存在不证明字段、数值或可用性合格，诚实说明未完成也不代替实际交付。

## 5. 缺陷归属、恢复与问题记录

一个可独立修复的问题只建一条finding。只有其他单元也有自己的关键失败证据时，才关联影响；不按标签或受影响单元数量重复计错。

可见错对象、错期间、错字段或错参数已用于任务时，可以确认候选责任，不等待隐藏成因。分析误解要求与已识别要求却未落实，按可见记录区分；没有分析时仍可确认行为违反，但不臆测具体内部原因。错误输入上的正确算术不自动判算错，正确材料中的错行错列主要归抽取，正确解析后误解业务概念主要归依据或逻辑。采集缺失、服务错误和候选错误分别定位。

已经确认且实际用于解题的候选过程错误，恢复后仍在原过程单元分档：局部、完整恢复且无重要残留时可为3分；仍有重要失效按2、1或0分锚点。最终交付、恢复处置和修正传播各自验收，修复后的终值不再作为当前错误。正常探索、合法对比和未采纳的试探不因与终值不同就算错，不按次数罚分。

“纠错未落实”需要候选实际收到正确、明确、适用的纠错，随后仍复现同错的前后证据。保留在原finding中，有后续行动处置失败才关联A2/A04；更正未传播到结论才关联U2/U04，不自动同时影响两项。错误或未送达的反馈、合法探索、服务再次失败不算候选复错。

问题记录保留可见表现、证据和受影响的诊断项。单次错误不能直接确证训练数据不足等内部成因，也不能据此推断样本准入或跨题聚类结论。

## 6. 题设约定与题目问题

明示数值、简化或反事实假设默认作为解题约定，不因现实中少见而制造矛盾。题目明确要求核验真实性或相容性时照题检查。

同一对象、时点和口径下的矛盾已确认且影响核心结果时，单独记录题目问题，并评价候选是否指出矛盾、合理说明无唯一解或给出条件结果。仅有专业疑点先记题目待核，不因候选未提出疑点扣分。不得用裁判自选的一组替代假设充当唯一金标；不受影响的计算与交付继续验收。

题目问题与候选缺陷分别记录，保存格式见 [题目问题记录](question-issue-policy.md)。局部数据疑点的特定校准例见 [校准示例](calibration.md)，其局部同档关系不能推广为一般规则。

## 7. 六维与12个核心单元

T1、T2、D1对准入的非空回答始终适用。其他单元按任务、回答和可见行为触发。

题目要求检查某项能力或交付时，即使候选未做，该要求仍适用；是否完成和证据是否取得分别判断。题目未要求且实际行为也未触发时，才记不适用。缺少过程记录不证明候选未做，也不证明做对；可由完整答案确认的遗漏或错误照常评价，依赖缺失记录的部分保留待核。不同有效解法可以触发不同的行为诊断，不因没有采用裁判偏好的工具或方法加减分。

| 维度 | 单元 | 检查范围与触发条件 |
| --- | --- | --- |
| 任务与交付 T | T1 对象、目标与公开约束 | 对象、目标、范围、期间、指标、单位及输出约束的识别与落实。 |
| 任务与交付 T | T2 必要覆盖与实际交付 | 题意所需对象、字段、子任务和成品的实质交付；计划、尝试和占位不等于交付。 |
| 依据与忠实 E | E1 依据追溯、范围与时点 | 任务要求外部资料，或回答依赖来源、日期、窗口、版本时触发。 |
| 依据与忠实 E | E2 抽取与主张忠实 | 提取字段或数字、作出重要可核事实或来源支持主张时触发。 |
| 逻辑与方法 L | L1 分类、比较、集合与计算 | 分类、比较、筛选、集合、排序或定量计算时触发；局部样本不能证明全集。 |
| 逻辑与方法 L | L2 推断与方法自洽 | 解释、推断、预测、假设或方法声明时触发。 |
| 行动与返回 A | A1 行动路径与参数 | 任务需要取证或行动，或候选使用影响交付的工具路径时触发。 |
| 行动与返回 A | A2 返回消费与失败处置 | 存在影响任务的返回、错误、空结果或恢复过程时触发。 |
| 不确定性处置 U | U1 缺失与冲突处置 | 关键资料缺失、覆盖不足或冲突影响结论时触发。 |
| 不确定性处置 U | U2 结论强度与修正传播 | 存在确定性、预测或泛化结论，或相关修正、撤回时触发。 |
| 呈现与可用性 D | D1 核心答案与展示对应 | 核心结果可定位，多对象和字段的展示映射清楚；不按文风偏好评分。 |
| 呈现与可用性 D | D2 成品可用与限制可见 | 任务指定格式或成品、实际交付成品，或存在影响使用的重要假设、缺口、限制时触发。 |

具体分数按 [分档标准](scoring.md) 中各单元的五档定义选择。

## 8. 24项细化诊断

每题保留全部24项。触发取决于候选任务和行为，不由裁判自己做了搜索或复算来触发。细项定位问题，不另计分；父项与细项必须各有适用依据。细项判违反须关联相应父项及finding。

| 细项 | 所属单元 | 检查内容与触发条件 |
| --- | --- | --- |
| T01 | T1 | 对象与目标识别：所有准入非空回答；检查是否替换实体、集合或任务。 |
| T02 | T1 | 约束识别与落实：所有准入非空回答；检查期间、指标、单位、范围和必要输出。 |
| T03 | T2 | 必要覆盖：所有准入非空回答；检查具体对象、字段和子任务是否实际完成。 |
| T04 | T2 | 交付完成：所有准入非空回答；按可见答案、文件或动作终态验收。 |
| E01 | E1 | 来源与范围：任务需要或候选依赖来源时；区分定位、可靠性、摘要与全文。 |
| E02 | E1 | 时点和版本：涉及截止、窗口、历史或修订时；检查相对接受日期的适用性。 |
| E03 | E2 | 字段与数值：提取属性、表格、数字或单位时；核对对象、行列及倍率。 |
| E04 | E2 | 主张与证据：作出重要可核主张时；检查支持、矛盾与不足。 |
| L01 | L1 | 概念和类别：涉及类别、状态或变化性质时；区分相近但不同的概念。 |
| L02 | L1 | 比较、集合、排序：涉及筛选或比较时；核对基准、同一主体、AND/OR、去重及全集。 |
| L03 | L1 | 公式与算术：候选使用计算或题目要求计算时；核对输入、公式、单位、运算和舍入。 |
| L04 | L2 | 推断与方法：存在推断、解释或预测时；核对假设、推导和结论，区分相关与因果。 |
| A01 | A1 | 路径适配：需要或采用取证、行动路径时；核对目标和公开限制，接受有效替代。 |
| A02 | A1 | 调用约束：实际调用或题目要求调用时；核对对象、过滤、日期、单位和参数。 |
| A03 | A2 | 返回消费：存在影响任务的返回时；核对对应、空值、分页、截断和错误状态。 |
| A04 | A2 | 失败与恢复：发生实际失败、关键空返回或收到有效纠错后；检查恢复、替代、停止及纠错落实。正常返回的错期调用也可能构成任务失败。 |
| U01 | U1 | 缺失与否定：缺资料、局部覆盖或空返回影响结论时；区分未查到、不可取得、未发生和不存在。 |
| U02 | U1 | 冲突处置：实际重要冲突、确认题设矛盾、题目要求核验冲突或校准例明确限定的疑点时；合理取舍或保留未知。单一来源不自动形成冲突。 |
| U03 | U2 | 结论强度：事实确定性、预测、泛化或投资判断时；检查证据和范围是否匹配。 |
| U04 | U2 | 修正传播：发生相关新证据、更正或撤回时；核对最终结论和说明是否同步更新。 |
| D01 | D1 | 核心答案定位：所有准入非空回答；用户能直接找到所问结果。 |
| D02 | D1 | 展示对应：多个对象、字段、表格或图表时；核对行列、标签、图例和引用映射，不把同一事实错误重复当展示错。 |
| D03 | D2 | 重要限制可见：存在影响使用的缺口、假设或限制时；检查是否清楚、相关且可见，内容真假仍由相应单元判断。 |
| D04 | D2 | 格式与成品可用：题目明确要求文本格式，或要求、交付文件、图表、代码、交互结果时；检查文本格式、成品可打开性、字段及行为是否符合任务。 |

## 9. 单题总分与交付范围

最终解答质量总分使用 [分档标准第4节](scoring.md) 的0–10分五档。它按最终交付独立判定，12个核心单元和24项诊断分别记录具体表现，不作总分公式。题目要求、已确认缺陷和具体未知共同限定可给出的评分；不因方法不同改变必要要求。

单题JSON必须保留全部固定评分单元和诊断编号、各项适用依据及证据引用，便于后续技能处理。当前Skill不选择共同可比题集、不计算模型胜负或训练效果，也不要求候选采用相同思路。身份关联和工具原始日志由执行器保存。
