在 candidate 的消息中搜索 query 的逐字子串，返回匹配片段及 reference；不支持语义搜索或正则表达式。scope 默认 all，按消息顺序搜索全部材料；tool_returns 只搜索原始工具返回，从新到旧排列，避开调用参数和模型历史中的重复文本。
已知来源时传 message_index 限定消息，传 path 限定原字段；两者可同时使用，避免重复命中历史指令与同一文本的 JSON 镜像。不限定消息时省略 message_index 或填 null，不能用 0 占位，0 表示只查第零条消息。path 使用目录中的真实路径。
命中原文本时直接返回其叶子字段路径，不同时返回同文 JSON 镜像；其他 JSON 字段名和结构化数值命中仍保留。context 按需附上来源开头和同对象的短文本字段，补充标题、日期、单位等线索，带独立证据编号；已读内容不再附送。context 和命中已足够时直接引用；仍缺同一对象的多个相关字段时，一次有界读取它们的共同父对象，不把标题、日期和来源拆成多次读取，也不无目的地扩读整个长返回。
核查数据依据时用 tool_returns 搜指标、对象或时间字段；回答中的舍入值、单位换算值可能不在原文，换用字段词定位。new_source_chars 是本次新增原文字符数，不表示事实数量或调查价值；重看已有原文也可能解决新的口径、条件或因果问题，already_read 表示该命中片段已展示；完整短来源或已读命中不再附 read_request，仍可按真实坐标补充明确缺少的上下文。匹配片段已包含判断所需原文时直接复用 reference；只有缺少对象、时点、单位、条件或原值时，按 read_request 补读相关上下文；入口已定位到命中附近，保留 offset 和小范围 max_chars，不重置为全文开头。需查指令、请求或模型实际输入时用 all。未命中只表示所选范围没有该字面词，不能证明相关事实不存在。
has_more=true 时，保持 candidate、query、scope、message_index、path 不变，将 next_offset 原样作为下一次 offset；切换范围或查询词从 offset=0 开始。引用使用对应 reference。
