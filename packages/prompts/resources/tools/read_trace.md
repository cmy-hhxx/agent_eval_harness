按 message_index 读取消息。已知正文路径时传 path（如 /content/0/text），只读取该字段；不知道路径时省略 path，先看返回的 text_sources 再选择。evidence 中每条 quote 与 evidence_id 成对，核对原文后直接复制完整 ID，不解释或修改 ID 内的数字和路径。has_more=true 时沿用相同 candidate、message_index、path，并把返回的 next_offset 原样作为下一次 offset；不要自行计算位置，也不要将整条消息的分页位置套用到正文路径。分页长度会按输出预算自动缩小，以返回完整的证据条目。 省略path时可用source_offset分页查看文本路径目录：text_sources_has_more=true时把text_sources_next_offset原样作为下次source_offset，正文offset与目录source_offset互不混用。必读的延后正文按明确path和next_offset连续读取，省略max_chars或使用16000；成功返回的新页使用独立必读额度。重复页、较小页长、目录检索和其他工具使用探索额度，工具结果会显示两种剩余额度。
