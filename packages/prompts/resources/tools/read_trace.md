按 message_index 读取消息。已知字段路径时传 path（如 /content/0/text、/output/datas/0 或 /output/code_count），可直接选文本、对象、数组、数字、布尔值或 null；程序自动返回对应原文片段和任务内正整数证据选号，无需计算字符坐标。字符串字段返回原始文本，结构化字段返回原消息 JSON 中的对应片段。未知路径时省略 path，读取消息及 text_sources 目录后再选择。evidence 中每条 quote 与 reference 成对；核对原文后将对应 reference.evidence_index 作为提交引用的选号。message_index、quote 和分页字段仅供阅读，不复制到提交引用中；不推算或虚构编号。has_more=true 时沿用相同 candidate、message_index、path，并把返回的 next_offset 原样作为下一次 offset；不要自行计算位置，也不要将整条消息的分页位置套用到正文路径。分页长度会按输出预算自动缩小，以返回完整的证据条目。 省略path时可用source_offset分页查看文本路径目录：text_sources_has_more=true时把text_sources_next_offset原样作为下次source_offset，正文offset与目录source_offset互不混用。必读的延后正文按明确path和next_offset连续读取，省略max_chars或使用16000；成功返回的新页使用独立必读额度。重复页、较小页长、目录检索和其他工具使用探索额度，工具结果会显示两种剩余额度。 来源和完整坐标由程序维护，提交只填已提供的 evidence_index，不另填 source。
