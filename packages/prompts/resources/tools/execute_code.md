在本任务工作目录执行 Python 或 shell，用于计算、定位材料或准备提交文件。材料位于 inputs/；盲测文件已匿名化，原文路径与字符坐标以 read_trace/search_trace 返回为准，不用匿名文件的偏移构造证据。中间文件使用相对路径。outputs 声明需要读取的产物；写稿时包含待提交文件名，例如 evaluation-draft.json。Python 写稿用 json.loads(r'''完整JSON''') 解析后再 json.dump(..., ensure_ascii=False)，不把含 null/true/false 的 JSON 直接当作 Python 字典执行。工具会读取并登记声明产物；exit_code=0 且无 errors 即表示执行及产物读取成功。artifacts 优先列声明产物，已完整展示的 stdout/stderr 不另给读取入口；日志截断时保留全文入口。
核算多个派生数值时，在一次调用中按各指标定义独立写出算式，按行打印对象/日期/指标、原值及证据编号、回答值、重算值和差异；有冲突时可用同一组变量生成问题草稿的事实句，避免提交时抄串期间或数字；不要复制候选公式当作独立验证。原值已展示且带证据编号时直接使用，不为计算再次读取同一材料。
批量定位 trace 时遍历顶层 messages，按真实调用关联提取工具名、请求中的说明或关键参数、返回自带的摘要/状态/错误、结构与数据量，以及 message_index 和原始字段路径。arguments 可能是 JSON 字符串，input/output/content 可能是对象、数组或文本，先查看结构再提取；没有可靠关联时保留未知。概览每步用短行，总输出控制在数千字符，标出截断；无摘要的长返回只列结构、规模和少量相关原文，不凭脚本生成语义结论。按需分批定位，不打印完整输入、长表格、媒体数据，也不递归展开 input_messages、模型参数或工具/skill 文档；只有调查特定疑点时才选取相关片段。
探索额度耗尽后，保留的写稿调用仅用于准备当前内容工具的 JSON。timeout_seconds 不超过预算的 code_timeout_seconds。
计算与概览输出辅助核查，不登记原文证据或完整阅读覆盖；引用原材料时用 read_trace/search_trace 读取对应消息与字段，选择其返回的 reference。失败时检查 exit_code、stdout、stderr 和 errors，修正后再计算。
