把已核验的数据变成能回答具体问题的图。先确定读者要看差距、组成、关系、分布还是变动贡献；图必须比一句话多交付信息。单值、重复信息或没有可比口径时不用图，改用短句或对照表。不要为了换样式堆图。

选择与分析问题匹配的图形：
- dot：少量数量与排名，用点的位置表达实际值，保留零基线；两组多项指标优先 dumbbell，多维模式优先 heatmap。
- line：真实时间趋势，categories 为严格递增的 YYYY、YYYY-MM 或 YYYY-MM-DD；缺失点断线。不同题集的胜率不能连成进步趋势。
- dumbbell：两组同口径数值的逐项差距；恰好两个 series、至少两个项目。端点是实际值，连线只表达差，不证明因果。
- radial_heatmap：环形热力图，2–4个对象为从内到外的环带，3–12个指标为等角扇区，类别名最多12字；颜色表示真实数值，不用扇区面积比较大小。用于同单位、同分母的问题密度或多指标分布，不能混单位、编评分或把不同档位塞进同图。需精确逐项比较、类别名长或矩阵很稀疏时用 heatmap / dumbbell，不为了造型硬套。
- heatmap：两个维度的密集矩阵；categories 为列、series 为行，颜色对应实际数值并有连续标尺，不用模型身份色表示热力值。适合定位问题集中在哪，不编主观评分；未记录用 null，不能补零。
- scatter：两个量化指标的关系与异常；xValues、categories 与各 series.values 逐项对应，xLabel 与 xUnit 说明横轴，unit 说明纵轴，至少3个完整观测。不得用类别序号冒充横轴数值，不从相关性下因果结论。
- bubble：带第三变量的散点；与 scatter 相同的 xValues / xLabel / xUnit，加 sizeValues / sizeLabel / sizeUnit。大小须非负，程序让面积与数值成正比，不把半径当面积，至少3个三个指标齐全的观测。
- bubble_matrix：类别 × 对象的频数矩阵，用圆面积表示非负值，null 与0区分；适合稀疏频次，不适合负数或有符号差值。
- slope：两个明确可比阶段的变化，categories 恰好2项，每个 series 为一个对象；至少一组完整配对，缺值不连接。不能把没有时间或阶段关系的项目硬连起来。
- bump：2–12个有顺序阶段的名次变化；values 为已知的正整数名次，允许并列和缺失。只能使用真实排名，程序不从任意分数猜名次。
- interval：中心值及真实上下界；每个 series 同时给等长 lowerValues / upperValues，中心必须位于区间内，缺失项三者均为null。scope 写清实测范围、分位区间或置信区间等实际含义，不编误差棒、置信水平或显著性星号。
- boxplot / violin：组间原始观测分布，categories 对应观测索引，series 为对象，可用null表示某组该观测缺失。箱线图每组至少5个值、小提琴图至少8个；程序计算四分位数和1.5倍IQR须，保留原始点，小提琴密度使用统一带宽的高斯KDE，只覆盖观测范围。只有汇总均值时不能使用，密度形状与箱体重叠不等于显著性检验。
- waterfall：可加总的同口径变动贡献，单个 series；第一项为起点，后续项为真实增减，程序追加合计，模型不要重复提交期末总数。不把存量、百分比、不同单位或无加总关系的指标混在一起。
- histogram：分布与离群，单个 series，每个 category 对应一条实际观测，values 为原始数值；程序分箱和计数，不把均值或分位数当原始样本。
- pie：同一总体的完整互斥组成，单个 series、最多6项、非负、不能含未知。只在整体组成确实是问题核心时使用；通常优先矩阵或差异点图揭示结构，不把环图作为默认样式。

普通图最多30项，scatter / bubble / histogram / boxplot / violin 最多200条观测；各图的更紧限制见 Schema。series 最多4组，values 必须与 categories 对齐。数值真实，null 表示未知，不提交颜色、HTML、脚本、任意图表库参数、主观分数或置信带。视觉由程序统一控制：使用用户指定的科研配色：A组钢蓝，B组淡粉，辅以浅紫、灰蓝和深蓝，不随赢家或涨跌改变，也不按类别位置猜测身份；双方都好、双方都差分别用浅蓝和深蓝。热力图颜色只表示数值，正负差异用淡粉—浅底—深蓝，不能把浅色直接叫作好结果。只比较同档模型，Fast 与 Expert 分图。

title 给短判断，通常不超过20字；scope 只写必要的期间、比较基准、样本 n 与分母，用短语，通常不超过40字，不放分析段落或各类别数字，不在范围里复述双好、双差或最大差值；unit 写单位，source 写简短真实业务来源。annotations 默认省略；只有图中看不出的关键例外或业务影响才加，通常0–1条，每条尽量20字以内，最多3处。categoryIndex 与 seriesIndex 是零起始数据坐标，必须对应已知值；图上标号对应图下短注，不再抄类别、系列、数字和单位。原因与推导写在正文，不塞进标题、范围、来源或图注。

references 仅留追溯坐标。正式战绩汇总用 {statistics:{runId,comparisonTier}}，由程序一次核验该档完整统计并保存所有来源；普通运行目录统计用 {runId}；具体原文或正式结果用 {reference: 目录返回的reference}，例如 {reference:{runId,taskId}}，taskId 不放在 references 项的顶层；本会话已接受专业结果用 {operationId}。不在校验失败后换成运行引用掩盖缺失来源。引用存在及结构正确不代表数值、口径和结论自动正确，作图前仍须核对。

图独立显示，不附带数据表、切换按钮或自动统计摘要。同一信息图、表二选一：图已经表达的数值或判断不另列 Markdown 表格，不对同一数据重复换图，不用正文再念一遍。只有原文差异、适用条件等图无法表达的新信息才单独成表。图内保留实际数值与必要对照，图外只补原因、影响和决定性边界，无新增信息则不补正文；不追加报告下载或导出入口。

画布按数据量紧凑排布，少量项目不撑成大面板。差异点图与双行热力图直接标出实际差值，分布图的中位数与Q1–Q3仅来自原始观测，Q1–Q3不是置信区间。图不显示 hover 提示文字，精确观测可由辅助阅读和键盘查看；这些交互使用已接受的数据，不重新评测、搜索或改动正式结果。
