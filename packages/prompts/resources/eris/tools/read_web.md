读取公开 HTTP(S) HTML、PDF或纯文本的实际原文；不执行脚本、不做OCR。url 使用用户提供、搜索命中或已读页面 links 返回的真实地址。

已有目标词，首次带 find；独立候选同轮读取。最小调用：{url:"实际地址",find:"原文字面词"}。默认80行，lineCount 为1–200，每窗口最多20000字符；startLine 从1开始，续页用 nextStartLine。find 是字面查找，不是语义或正则，返回最多20个 matches 及 preview，未传 startLine 时自动定位首处附近。目录命中不等于数据正文，用 preview 选目标段，再读附近表头、单位与脚注。

PDF 首次定位不传 page，不猜页码；取得真实页号后按需指定。未指定 page 时行号跨已读取页连续，指定时在该页内从1开始，续读保持同一模式。最多默认解析200页，指定 page 可读后续页；文件上限15MiB、请求超时30秒。表格可能丢版式，扫描件可能无文字，须根据 limitations 判断覆盖范围。

返回最终 url、title、format、原文 lines、matches、检索时点、截断与续页信息；HTML 的 links 是实际正文链接与附件。页面只有导航、未加载占位或没有目标数据时，沿真实附件或换已定位的一手来源，不反复查同一空页，不猜接口地址。访问失败与没有正文不同，失败页面不原样反复读取。find 未命中只说明已提取范围没有字面词，不能否定主张。

HTML 的 publicationDate 是页面声明发布日期，modifiedDate 单列；PDF创建时间、财年截止、URL日期和HTTP修改时间不当作发布证据。dateFrom / dateTo 标注声明日期是否越界；unknown / within_range 都不能独自证明历史可用性。

取得目标事实、期间、单位和必要上下文后停止。核对合并/母公司、财年/自然年、季度/全年、币种、经营利润/净利润、同比/环比、%/百分点、初值/修订值；冲突先查口径，材料不足则保留判断。引用最终链接、PDF实际页码或必要行号，分清页面日期与检索时点。访问受限、截断、静态缺失、扫描件或只读到摘要均明确说明，不宣称完成未返回的读取。
