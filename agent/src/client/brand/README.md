# Eris 标识

[tonghuashun.png](tonghuashun.png) 为[同花顺官网](https://www.10jqka.com.cn/)的官方透明 PNG，保留原始 32 × 32 像素文件；[原始来源](https://s.thsi.cn/cd/news-p-fe-app-news-flow-home/home/_next/static/media/icon.14a881d7.ico)获取于 2026-10-13（地址后缀为 ico，内容为 PNG）。

[brand.js](../brand.js) 将同一标识用于侧栏、欢迎页和运行状态；[index.html](../../../index.html) 用于浏览器图标。名称保留 Eris。

界面固定浅色；品牌模块通过主题 token 将发送与主操作、链接、焦点和选中态统一为朱红 `#b74a3d`、悬停深红 `#9f3338`，消息气泡与选中背景使用淡红。状态语义色和图表数据配色独立保留；最高思考档的深红至暖金粒子效果由模型选择组件维护。
