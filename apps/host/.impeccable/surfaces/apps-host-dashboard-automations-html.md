# 自动化监控页

[设计基线](../DESIGN.md) · [运行与数据语义](../../../../docs/automations.md)

页面：`apps/host/dashboard/automations.html`。只读监控，不启动、重试或上传任务。

## 信息层级

1. 顶部给出运行状态、更新时间、错误日志入口与刷新按钮。
2. 概览独立于表格筛选：评测器、实时并发、待重试、最近重试、累计缓存命中率，以及取数、评测、MongoDB 和日志四通道状态。并发只统计活进程；断连保留快照但不继续预测倒计时。
3. 日期进度、时段完成量、MongoDB 交付、日志交付分别占一个页签，每次只显示当前区块。只显示该页签适用的日期与时间筛选；重置只作用于当前区块。
4. 每张表每页 10 条，提供页码、记录范围和翻页；自动刷新保留筛选与分页，数据变少时收敛到最后一页。统计值覆盖全部筛选结果，不只统计当前页。

状态同时用文字和颜色表达。数量按四模型分别核对，远端与本地不一致时展示差额，不标为就绪；没有输入 Token 与有输入但缓存未命中分别显示“暂无用量”和 0%。窄屏保持页面不横向溢出，页签与表格可独立横向滚动。

功能回归见 [`automation-dashboard.test.ts`](../../../../tests/integration/host/automation-dashboard.test.ts)。视觉验收使用当前页面和数据，不把旧截图、历史条数或某次测试数量当成长期契约。
